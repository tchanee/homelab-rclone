homelab-rclone

homelab-rclone is a personal backup tool used by its owner, Johnny B., to store encrypted backups of his own home server in his own Google Drive account (using rclone and restic).

It is not offered to anyone else, has no other users, and has no public sign-up.

It requests only the https://www.googleapis.com/auth/drive.file scope, which means it can see and change only the files it created itself, not any other file in the Drive.
