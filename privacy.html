Privacy policy: homelab-rclone

Last updated: 1 November 2026

homelab-rclone is a personal backup tool. Its only user is its owner, Johnny B., who uses it to back up his own home server to his own Google Drive.

What Google data it accesses

Only the drive.file scope: files and folders the tool creates in the owner's Google Drive (encrypted backup files). It does not read, list or change any other file in the Drive, and it does not access email, contacts or profile data beyond what Google needs to sign in.

How the data is used

The data is used only to write, read, check and prune the owner's own encrypted backups. Backup contents are encrypted before upload, so they are unreadable in Drive.

Sharing

No data is sold, shared with or transferred to anyone. There are no analytics, ads or third-party services. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

The OAuth token is stored only on the owner's own server. Access can be revoked at any time at myaccount.google.com/permissions; deleting the backup folder in Drive removes the data.
